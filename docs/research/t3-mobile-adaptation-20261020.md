## Selected batch and boundaries

Search snapshot invalidation uses calendar version/readiness/visibility, day/time-zone and requested range. Query text and local mirror IDs do not trigger new EventKit reads; mirrors are filtered locally. Empty suggestions, reminder-only/alarm-only queries and disabled Calendar do not query Calendar. Upcoming-events suggestions use a bounded week range; query search retains the existing two-years-either-side scope and upcoming-then-recent-past ordering. Snapshot display is rejected immediately when its key is stale, including disable/permission changes.

The first range load still calls the existing synchronous MainActor adapter **outside rendering**; this does not prove that a cold EventKit query cannot stall the main thread. A dedicated asynchronous scalar reader would be a larger adapter seam and needs measured cold-query evidence. No latency/FPS/memory speedup is claimed from source inspection or reduced call counts.

No changes to Today layout, grouping, 44pt targets, Dynamic Type, dark mode, source mutation, approvals, AI creation, or phone installation. In particular, Settle/Snooze remain local attention state: no completion, original time/alarm/repeat changes, terminal shutdown, run-on-settle, server routing or autoresume behavior is imported.
