Agent 活动板

侧边栏里的 “Activity”。这是控制平面的核心：一本只追加的账本，记录意图（你想达成什么）→ 动作（谁做的：你、Today AI、哪个外部 agent，何时，经由什么通道）→ 结果（写到了哪里、批准 / 拒绝 / 失败 / 撤销）。

三种视图

  • Timeline：像 T3 Code 左侧的 thread 列表 + 日志，按时间倒序，可按 agent 过滤。点一行看账本原始记录（JSON）。
  • Board：按意图分泳道，进度条显示已完成 / 待批 / 失败，最后一行是“下一步谁来做”。
  • Graph：一个意图的关系图。实线 = 已发生，虚线 = 等你批，红 = 失败，灰 = 被拒。

和编码 agent 面板的对应

  • thread ↔ 意图；diff ↔ 改前 → 改后；merge ↔ Approve；revert ↔ Undo；权限档位 ↔ 四级自主权。

Trip / Inbox / Coding agent 都是虚构的例子，代表“Mac 上通过 MCP 接入的任意 agent”。
