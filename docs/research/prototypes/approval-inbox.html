审批收件箱

所有 agent（Today AI、Mac 上的 Trip / Inbox / Coding agent、快捷指令）提出的改动都进这里。每张卡说清楚：谁、改什么（改前 → 改后）、为什么、影响范围（写到哪个 Apple App、会不会通知别人、能不能撤销）。

四级自主权

  • 0 观察：只读、只记录，从不打扰。
  • 1 本地：只改 Today 自己的副本（计划时间、链接、账本里的备注），可以给某个 agent 长期放行，一键撤销。
  • 2 Apple App：写 Apple 日历 / 提醒事项 / 闹钟。默认要问；可以“对这个 agent、这类改动、这个列表，放行 30 天”。
  • 3 他人 / 不可逆：通知别人、删除、发送、花钱。永远要问，不能预先授权。

试一试

  • 批准一张卡，再点 Undo。
  • 勾选“Always allow…”再批准，看看 Allowed 区和右上角权限表。
  • Weekly sync 那张卡没有放行选项（第 3 级）。
