Today · AI-native 原型

配合 docs/research/ai-native-vision.md 阅读。界面文字用英文（与 App 一致），右侧 / 下方是中文设计说明。数据来自 tests/fixtures/today-dataset.json，第 0 天固定为 2026-10-15 周四 9:41；agent、天气、路程、睡眠都是虚构的。无网络请求，不保存任何东西，刷新即重置。

1 · AI 规划的 Today实时信号 → 计划更新卡（逐条勾选、写到哪里、Apply / Undo）；可以模拟“会议拖堂”“牙医取消”“没睡好”，看计划怎么跟着变。 2 · 审批收件箱所有 agent 的提议集中在一处：谁、改什么、为什么、影响范围；四级自主权；按 agent × 改动类型的限时授权。 3 · Agent 活动板控制平面：意图 → 动作（谁、何时、经由什么）→ 结果。Timeline / Board / Graph 三种视图，点开看账本原始记录。 4 · 晚间复盘计划 vs 实际、没做完的去哪、Today 学到了什么（时长校准、可加入端侧评测集）。
