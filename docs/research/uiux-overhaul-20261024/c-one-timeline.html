方向 C · 一条时间线（激进）

只剩 2 个 tab：「日程」是一条连续的时间线（逾期 → 今天 → 明天 → 往后），events、提醒和闹钟都在上面；「列表」管没有日期的东西和 My Lists。月历和年历是点标题就能展开的“缩放”，不再单独做一个 tab；Clock 工具移进侧栏。点击数和 B 一样（18），但地点更少：要决定“去哪个 tab”的情况从 4 个降到 2 个。代价是放弃“先在屏幕和手势上对齐 Apple”这条路线。

C 会破坏的东西（需要卢元拍板）

和原则 / 路线冲突原则

  • CLAUDE.md 的路线是先对齐 Apple 的屏幕和手势，证明对齐之后再超越。C 拿掉了 Apple 式的 Week 网格默认页和 Clock tab，等于提前进入“超越”阶段
  • Rubric 维度 1（Calendar）中的 Week/Month 主屏、维度 3 的 Alarms 页都需要重写

工程代价

  • 新的无限 agenda（跨天分页，跨天数据要按区间加载，不能一次读完）
  • Calendar 改成缩放：CalendarView 大改，Year 缓存要重新接
  • TabMemory、widget 深链、Quick Actions、大约 40% 的 UI 测试需要重写

好处

  • “今天”只剩一个地方。现在有 Today tab、Reminders 的 Today 智能列表、Calendar 的日视图三处
  • “看明天 / 下周”不用切换任何东西
  • 概念数量最少
