## Cause and behavior

`focus-v1.json` keys decisions by provider/account/calendar/item/occurrence and
stores `state`, `changedAt`, and an opaque local reference. Read projection expired
only Snooze; Settle returned indefinitely, including in the Settled disclosure.

Settle now projects only on the local calendar day of `changedAt`. Expiry is
read-only: no record deletion, timestamp rewrite, Activity pruning, completion,
source write, reschedule, alert/repeat change, or EventKit read in SwiftUI body.
Yesterday's event therefore leaves Settled and follows the existing occurrence
filter, which excludes it from today's regular timeline. Expired Settle does not
enter the Snooze/explicit-Restore return inbox. Overdue reminders follow the existing
overdue predicate, and can be settled again today. Undo cannot renew a prior-day
Settle. Snooze retains its absolute instant and existing return behavior.

DayAgenda reuses its pre-existing 60-second clock refresh, appearance and foreground
callbacks. There is no new polling or service. Today follows the new day while an
explicitly browsed date stays selected. Home retains the previous Today reference
across tab destruction/recreation, including an overnight stay on Clock.

Calendar semantics intentionally follow the existing `PlannerRuntime.calendar`
(`Calendar.current` captured by the live session), also used by presentation and
source filtering. Day equality handles 23/25-hour DST days rather than elapsed
24-hour intervals. Clock changes compare the supplied instants in that same calendar;
a timezone preference changed during a session does not introduce a new dynamic
calendar policy here. A fresh session uses its newly captured local calendar.
