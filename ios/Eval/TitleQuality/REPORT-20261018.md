# Title evaluation audit and baseline — 2026-10-18

## Existing evaluation and gaps

- `CaptureEvalTests.swift` exercises the rule parser from its package-bound
  `capture-cases.json`: exact title and capture fields; it does not establish
  Apple Intelligence quality, chat routing, note retention or confirmation gates.
- `Understanding/main.swift` invokes the parser and availability-gated Foundation
  Models variants, checks kind/day/hasDay/hour/minute/duration/repeat, and accepts
  normalized exact title or word/character F1 >=0.7. Motivation in titles and raw
  fragments can retain enough overlap to pass. It processes one input at a time;
  notes, route, multi-item previews, chat history and user confirmation are absent.
- `open/score_open.py` accepts title substring containment in either direction,
  which can reward truncated fragments. It scores stored model/parser outputs,
  not the actual Ask UI. `run_openai.py` uses a separate hosted model and prompt;
  such runs would not prove the on-device app's behavior.
- `Understanding/RESULTS.md` records older macOS-model results and explicitly
  excludes phone-model/latency evidence. It reports follow-up weaknesses; those
  historical numbers were not rerun here. `run-eval.sh` builds/tests broadly and
  does not fill these quality gaps; it was not run in this host-only lane.

## Authorship, executor, scorer and observations

**Authored:** 38 cases / 46 turns (25 development, 13 reserved, not blind).
The stable fixtures carry alternative titles and semantic facts, not one exact
expected output or a length cap. Source/JSON loading succeeds.

**Runner adaptation:** the new Python companion accepts exported per-turn
observations, preserves missing evidence and splits deterministic field scoring
from attributed quality review. It does not execute the app/model. An actual
Ask/device export adapter remains future work; README specifies its contract.

**Scorer checks:** 7/7 Python tests passed (host-only, under one second). They check missing
results, paraphrase acceptance, wrong time/pre-confirmation write, semantic
violation, duplicate observations, split isolation and quoted-title preservation.
They are evaluator regression checks, not 38 application/model passes.
